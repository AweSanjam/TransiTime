Transi-Time

Live departures from the transit stop nearest to you, right on your wrist. Every route at the stop, real-time countdowns for each direction, refreshed every 25 seconds while open.

Download from Releases Source on GitHub Open source
Wear OS

What it does

  • Finds your location and picks the closest stop, with distance and last sync time.
  • Every route at the stop with the next departures in each direction; a pulsing dot marks real-time times.
  • SkyTrain and other rail lines in their own colour, apart from buses.
  • Pin routes to keep them at the top.
  • Full departure list per direction, with countdowns and clock times in 12 h or 24 h (follows the watch).
  • Data from Transit (API key) with keyless Transitous as the fallback. Pick Auto, Transit or Transitous in Settings.
  • Location and network are used only while the app is on screen.

Three layouts, same features

Triple-tap with two fingers anywhere to switch: Classic → Pod → Radar.

Classic

Material 3 cards in a scrolling list. Swipe a card to switch direction, tap for all departures, hold to pin.

Pod

An iPod-style menu in radar green. Nothing is a button: drag or turn the crown to move, tap anywhere to open, hold to pin, swipe right to go back.

Radar

Each route is a blip; pinned routes sit inside the dashed ring. Pinch or turn the crown to zoom; at 1.6× each blip shows its next times. Tap the centre to sync.

Install

Download TransiTime.apk from Releases and sideload it on a Wear OS 3+ watch:

adb -s <watch> install -r TransiTime.apk

Build from source

Needs JDK 17 and the Android SDK (compileSdk 35). Put your own free Transit API key in local.properties (never commit it):

cp local.properties.example local.properties
# edit transit.apiKey=YOUR_KEY
./gradlew assembleRelease

Without a key the app uses Transitous only.

The original project folder was lost. recovered-partial/ holds the recovered Kotlin sources (activity, the three layouts, controller and both data sources); the Gradle files and resources still need to be recreated before it builds.
